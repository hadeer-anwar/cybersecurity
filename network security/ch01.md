# Network Security – Summary Notes

## 1. CIA Triad of Security

The CIA Triad is the foundation of network security. It consists of three main principles:

1. Confidentiality

Ensures that only authorized users can access specific systems or data.

Example: Using passwords and encryption to protect private information.

2. Integrity

Ensures that data remains accurate and is modified only by authorized users.

Example: Preventing an attacker from changing a student's grades.

3. Availability

Ensures that authorized users can access systems and data whenever needed.

Example: Keeping a university website available to students.

Remember: CIA = Confidentiality + Integrity + Availability.

## 2. Network Security Zones

Dividing a network into separate security zones helps isolate systems and control access between them.

- Internal Network Zone: Contains private systems and resources used within an organization.
    
- DMZ (Demilitarized Zone): A separate zone for public-facing services, such as web servers, that need to communicate with external users.
    
- External Network Zone: Represents external networks, such as the Internet, which are less trusted.
    

Purpose: To limit unauthorized access and prevent an attack in one zone from spreading easily to other zones.

## 3. Network Security Components

- Firewall: Controls network traffic according to predefined security rules.
    
- Router: Forwards packets between networks.
    
- Web Server: Hosts websites and provides web content to users.
    
- Security boundaries: Separate network zones and help control traffic between them.
    

## 4. Risk Assessment

Risk assessment helps identify and evaluate potential security risks.

The infographic presents the relationship as:

\[ \text{Risk} = \text{Threat} \times \text{Vulnerability} \times \text{Impact} \]

- Threat: Anything that could cause harm to a system, such as an attacker or malware.
    
- Vulnerability: A weakness that a threat could exploit.
    
- Impact: The damage caused if the threat successfully exploits the vulnerability.
    
- Risk: The potential for loss or damage resulting from a security incident.
    

Example: An outdated web server has a vulnerability. An attacker exploits it, causing the website to become unavailable. The resulting service disruption is the impact.

## 5. Key Points to Remember

1. Confidentiality protects data from unauthorized access.
    
2. Integrity protects data from unauthorized modification.
    
3. Availability ensures systems and data remain accessible.
    
4. Network segmentation divides a network into separate security zones.
    
5. A DMZ helps isolate public-facing services from the internal network.
    
6. Threats exploit vulnerabilities and can cause harmful impacts.
    
7. Risk assessment helps organizations identify and prioritize security problems.
    

# ملخص Network Security – أمن الشبكات

أمن الشبكات هو حماية الشبكة والأجهزة والبيانات من الاختراق أو الوصول غير المصرح به.

### 1. مثلث أمن المعلومات (CIA Triad)

- Confidentiality – السرية: البيانات يشوفها الأشخاص المصرح لهم فقط. مثال: حماية الملفات بكلمة مرور.
    
- Integrity – سلامة البيانات: الحفاظ على صحة البيانات ومنع تعديلها بدون تصريح. مثال: منع شخص من تغيير درجات الطلاب.
    
- Availability – التوافر: الأنظمة والبيانات تكون متاحة للمستخدمين المصرح لهم وقت الحاجة. مثال: موقع الجامعة يفضل شغال.
    

### 2. تقسيم الشبكة إلى مناطق أمنية (Security Zones)

بنقسم الشبكة لمناطق لتسهيل حمايتها والتحكم في الاتصال بينها:

- Internal Network Zone: الشبكة الداخلية الخاصة بالمؤسسة.
    
- DMZ Zone: منطقة بتحتوي على الخدمات المتاحة للمستخدمين من خارج المؤسسة، زي Web Server.
    
- External Network Zone: الشبكات الخارجية، زي الإنترنت.
    

الهدف: لو حصل اختراق في منطقة، نقلل احتمالية وصول المهاجم لباقي الشبكة.

### 3. تقييم المخاطر (Risk Assessment)

بنقيّم المخاطر من خلال 3 عناصر:

- Threat (التهديد): حاجة ممكن تسبب ضرر، زي Hacker.
    
- Vulnerability (الثغرة): نقطة ضعف في النظام ممكن المهاجم يستغلها.
    
- Impact (التأثير): حجم الضرر الناتج عن الهجوم.
    


Risk = Threat × Vulnerability × Impact

يعني كل ما التهديد والثغرة والتأثير يكونوا أكبر، المخاطر المحتملة بتكون أعلى.

### الخلاصة

هدف أمن الشبكات هو تحقيق السرية، وسلامة البيانات، والتوافر، وده عن طريق تقسيم الشبكة لمناطق آمنة وتقييم المخاطر لتقليل فرص الاختراق والأضرار الناتجة عنه.
