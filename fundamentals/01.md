
# Cyber Security Field — Notes

## 1. Cyber Security Ecosystem

Cyber Security is **not one job**. It consists of different companies, teams, and roles that work together.

### Main players:

1. **Vendors** → Build security products.
    
2. **System Integrators** → Combine products from different vendors into one solution.
    
3. **Security Service Providers** → Provide security services.
    
4. **Customers** → Organizations that need security.
    
5. **Regulatory Entities** → Set regulations, policies, and standards.
    

---

## 2. Vendors

Companies that manufacture security products.

### Products:

- Antivirus
    
- Firewall
    
- IPS
    
- WAF
    
- SIEM
    

### Examples:

- IBM
    
- Palo Alto
    
- Fortinet
    
- Cisco
    

### Jobs:

- **Technical Implementer** → Install & configure products.
    
- **Technical Support** → Solve customer technical problems.
    
- **Security Sales** → Sell security products/solutions.
    
- **Security Architect / Consultant** → Design solutions for customer problems.
    
- **Product Manager** → Manage product requirements, priorities, and roadmap.
    

---

# 3. System Integrator

Acts as a **middle layer between Customer and Vendors**.

```text
Customer
   ↓
System Integrator
   ↓
Multiple Vendors
```

### Main role:

Combine products from different vendors into **one integrated solution**.

### Jobs:

- Technical Sales / Architect
    
- Technical Implementer
    
- Customer Support
    
- Sales
    
- Technical Project Manager
    

---

# 4. Security Service Providers

Provide security **services**, not just products.

Main services:

### A. Security Assurance

Goal → **Find vulnerabilities and weaknesses.**

Includes:

- Penetration Testing
    
- Secure Code Review
    

Role:

- Penetration Tester
    

Output:

- Vulnerability / Security Report
    

---

### B. GRC

**GRC = Governance, Risk & Compliance**

Goal → Make sure the organization has an effective security system and follows required standards/regulations.

#### Roles:

**Security Auditor**

- Checks security controls against standards and regulations.
    

**Information Security Consultant**

- Helps build the organization's overall security strategy.
    

**Security Risk Analyst**

- Identifies threats and evaluates risks and their impact.
    

---

### C. SOC

**SOC = Security Operations Center**

Goal → **Monitor systems, detect attacks, investigate incidents, and reduce damage.**

#### Roles:

**SOC Analyst**

- Monitors security events and alerts.
    

**Incident Handler**

- Investigates and coordinates response to security incidents.
    

**Threat Hunting / Threat Intelligence**

- Proactively searches for threats.
    
- Collects information about possible/current attacks.

# 7. How Security Teams Work Together

Typical security process:

```text
GRC
 ↓
Defines requirements & identifies risks/assets
 ↓
Penetration Tester
 ↓
Finds vulnerabilities
 ↓
GRC
 ↓
Evaluates the risk
 ↓
Security Planning / Architecture
 ↓
Designs the solution
 ↓
Security Administrator / Implementation
 ↓
Implements the solution
 ↓
SOC
 ↓
Monitors for attacks
 ↓
Incident Response
 ↓
Handles attacks/incidents
```

So cybersecurity is a **continuous process**, not separate isolated jobs.

# 8. Cyber Security Colors

### 🔴 Red Team — Offensive

Goal:

> **Attack the system ethically to find weaknesses.**

Examples:

- Ethical Hacking
    
- Penetration Testing
    
- Red Teaming
    

**Red = Attack**

---

### 🔵 Blue Team — Defensive

Goal:

> **Protect, monitor, and defend systems.**

Examples:

- Security Engineering
    
- Security Administration
    
- SOC
    
- Incident Response
    

**Blue = Defense**

---

### 🟣 Purple Team

Combination/collaboration between:

**Red + Blue**

Red finds attack techniques/weaknesses → Blue improves defenses.

Also commonly associated with activities such as:

- Threat Hunting
    
- Security improvement through collaboration

# ⭐ Most Important Takeaways

### Cyber Security has several major paths:

|Path|Main Goal|
|---|---|
|🔴 Pentesting / Red Team|Find weaknesses by attacking|
|🔵 SOC / Blue Team|Detect and defend against attacks|
|🟣 Threat Hunting|Proactively search for threats|
|GRC|Governance, Risk & Compliance|
|Security Engineering|Build and implement security solutions|
|Security Administration|Manage security infrastructure|
|Security Architecture|Design security solutions|
|Threat Intelligence|Understand current/emerging threats|

### Foundation:

**OS + Networking + System Administration + Programming/Scripting + Security Fundamentals**

↓

**Choose a specialization**

↓

**Practice with Labs + CTFs + Projects**

↓

**Internship / Job**

### One sentence to remember:

> **Cyber Security is an ecosystem, not a single career; first build your technical foundation, then choose the specialization that matches your interests and practice it hands-on.**
